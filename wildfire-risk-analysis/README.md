\# Wildfire Risk \& Severity Analysis



\## Project Overview

This project analyses wildfire risk and severity using environmental data such as temperature, humidity, wind, and rainfall.



The aim is to understand:

\- what environmental conditions increase wildfire risk

\- what factors influence wildfire severity

\- how data can support wildfire prediction and preparedness



\## Tools Used

\- Python

\- Pandas

\- Matplotlib / Seaborn

\- Power BI
